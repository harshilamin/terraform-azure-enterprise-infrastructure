# Enterprise Azure Landing Zone

This release packages the current stable version of the Terraform Azure enterprise infrastructure portfolio.

## Highlights

- Reusable Azure Terraform modules
- Dev, QA, and Production environments
- AKS platform engineering
- Hub-and-spoke networking
- Private endpoints and private DNS
- Shared Azure services
- Monitoring and alerts
- CI/CD reference workflows
- Native Terraform tests
- MkDocs documentation site
- Governance and release automation

## Validation

The release workflow checks Terraform formatting and validates Dev, QA, and Prod before creating the GitHub Release.
